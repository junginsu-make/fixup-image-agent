# 와디즈 출시 상품 비교안

2026-09-22 · 사용자 제안의 비교안. 실제 결제 상품·크레딧 지급 정책을 변경하지 않는다.

## 최초 사용자 제안 (비교용)

| 상품 | 판매가 | 기본+보너스 | 이월 |
|---|---:|---:|---|
| 베이직 구독 | 월100,000원 | 100+15=115크레딧 | 월 제공분 소멸 |
| 프리미엄 구독 | 월200,000원 | 200+30=230크레딧 | 월 제공분 소멸 |
| 구매 크레딧 | 100,000원(동일 가격 비교용 가정) | 100+15=115크레딧 | 잔액 이월 |

사용자 확인: 와디즈 수수료는 우선 **총15%**로 가정한다. 모집 이벤트는 아직 미정이므로 무료 크레딧 지급과 현금 광고/경품 예산을 각각 비교한다. 최소 마진 목표는30%.

사용자 추가 설명에 따라 판매가는 부가세 포함, 목표 마진의 분모는 **고객이 구매한 금액 전체**로 확정한다. 기존 순매출 기준 저장안은 재현하되 새 계산은 구매금액 기준이다. 비용에는 API·서버·DB·지원·광고·무료 지급·채널 수수료가 모두 들어가야 한다. 이 문서는 세무/회계상의 확정 손익이 아니라 판매건별 운영 예산이다.

## 크레딧 정책을 먼저 구분

현재 체크아웃은 기존 `cost-v1`과 새 `image-v2`를 함께 지원한다. 새 정책은 6백만 픽셀 미만 최종 이미지1장=1크레딧, 그 이상2크레딧이다. 기획·내부 슬롯·서비스 재시도는 회사 원가에 포함되지만 최종 이미지 외에 회원에게 추가 차감하지 않는 경로다. 실제 운영 계정에 새 정책이 적용됐는지는 이번 작업에서 확인하지 않았다.

따라서 새 정책의 일반 이미지 기준으로115크레딧은 최대115장이다. 이전 대화의 약23장은 원가 환산 정책 기준이었다. 구매자가 보는 제공량을 구정책과 섞지 않는다.

현재 코드상 구매 크레딧 유효기간은 지급 후3개월, 구독 크레딧은 한국시간 다음 달1일에 소멸한다(`packages/shared/src/credit-policy.ts`). **이월 가능은 무기한 유효와 다르다.** 결제일부터 한 달 서비스를 판매하려면 월말 소멸 규칙과 상품 안내가 맞는지 별도 결정해야 한다. 계산기의 운영비 적립 기간을 바꾸어도 실제 크레딧 만료일은 바뀌지 않는다.

## 상품 차별화에 대한 판단

1. 베이직115개/10만원과 프리미엄230개/20만원은 둘 다 크레딧당 약870원이다. 프리미엄은 두 배 용량이며 추가 할인은 없다. 더 큰 보너스를 즉시 확정하지 말고 재생성·지원·이벤트 비용까지 확인한 다음 조정한다.
2. 구매 크레딧에도 동일15% 보너스와 이월을 주면 출시 기간에는 구독 대비 구매형의 편의가 더 크다. **구독15%는 매 갱신 제공, 구매15%는 와디즈 최초 구매/기간 한정**이라는 차이를 두는 안이 적절하다. 이는 제안이며 실제 구매 제한·지급 자동화를 구현한 상태는 아니다.
3. 추가 이벤트 크레딧은 구독/와디즈 보너스와 별도 비용으로 계산한다. 동일 인원에게 여러 혜택을 줄 경우 합산 제공량을 공개한다. 무료 체험자를 유료 구매자와 중복해 회원 수에 더하지 않는다.
4. 장당 가격만 소개하기보다 일반 이미지, 카드뉴스 세트, 상세페이지 작업을 얼마나 할 수 있는지 함께 보여준다. 선택 모델·크기·추가 생성 조건을 명시한다.

## 30% 마진을 위한 예산

총 수수료15% 가정에서:

`API+운영+모집에 쓸 수 있는 금액 = 판매가/1.1 − 판매가×15% − 판매가×30%`

- 베이직: 약45,909원.
- 프리미엄: 약91,818원.

이 금액 안에 보너스 전량 사용, 실패, 재생성, 무료 체험, 광고, 지원, 인프라가 모두 들어가야 한다. 미사용 크레딧이 많을 것이라는 가정으로 최소 마진을 보장하지 않는다.

새 이미지 정책·표준형1024 정사각·기획/첨부 없음·환율1,380원·베이직115개 전량 소진 예시:

| 원가 가정 | API 비용 | API를 제외하고 남은 운영·이벤트 예산 |
|---|---:|---:|
| 추가 시도/최종 실패 없음 | 약33,441원 | 약12,468원 |
| 서비스 추가 생성25% + 최종 실패5%(실패 비용100%) | 약43,562원 | 약2,347원 |
| 서비스 추가 생성50% + 최종 실패5%(실패 비용100%) | 약51,922원 | 이미 목표 초과 |

이는 특정 입력 사례다. 비싼 출력 크기, 여러 슬롯, 무료 분석, 추가 지원은 원가를 바꾼다. 판매 전에는 허용할 모든 작업 조합과 가장 비용이 큰 사용 패턴을 확인해야 한다. API 비용뿐 아니라 실제 인프라·이벤트 금액이 채워져야 목표 충족을 표시한다.

## 수수료 대조

2026-09-22 확인한 [와디즈 국내 공식 안내](https://helpcenter.wadiz.io/hc/ko/articles/25375315142169)는 서비스12% + 결제/정산3% + 프로젝트 기본료99,000원이고 모두 VAT 별도다. 컨설팅은 추가 조건이다. 사용자가 확인한 최종 계약은 아직 없다.

계산기에 두 선택지를 둔다.

- **사용자 가정:** 총15%, 프로젝트 고정료 기본0(수정 가능). PG3.3%를 또 더하지 않는다.
- **공식 현금 공제 비교:** 16.5% +108,900원, 국내 기본·컨설팅 제외. 수수료VAT를 현금 유출로 포함하는 보수적 비교이며 매입세액 처리는 별도다.

공식 조건이 적용되면 구매100건 기준으로 프로젝트 기본료는 건당1,089원이며, 10만원 상품의 비율 수수료도 사용자 가정보다1,500원 늘어난다.

## 구현 위치와 사용

`/admin/cost-lab` 통합 요약 아래 **와디즈 상품 전략**을 펼친다. 3개 상품의 가격·기본 크레딧·보너스·예상 구매자·구매형 운영비 적립 기간, 수수료 가정, 모집 광고비, 추가 체험자·무료 크레딧을 바꿀 수 있다.

- 첫 회원 그룹의 작업 비중·모델·재시도/실패 조건을 재사용한다.
- 상품 구매자 전원이 보너스까지 소진하는 조건으로 API와 인프라를 다시 계산한다.
- 임시 AWS 혜택이 끝나도 유지할 수 있도록 인프라 원가는 혜택 전 값을 사용한다.
- 인프라/이벤트 공통비는 입력한 전체 구매자 수로 배분한다. 구매형은 선택 기간 운영비를 적립한다. 이는 판매건별 예산 비교이며 미사용 충전금을 당기 이익으로 인식하는 장부가 아니다.
- 행사와 구매자는 별도 집단으로 가정한다. 중복 인원 제외를 입력란에 표시한다.
- 인프라 누락/한도 초과/구매자0일 때 목표30% 충족을 확정하지 않는다.
- 공유 링크·비교안·HTML 다운로드·설정JSON에 상품 전략도 포함한다. 기존 공유 파일도 읽는다.

검증: 상품 전략7개 테스트, 기존 예측·접근 제어 포함86개 테스트, 기존 계산159개·충전형82개·시장 데이터 검증, web 타입 검사 통과. Chromium에서 수수료 전환·이벤트 입력·v3/HTML 왕복·입력 오류·1440/1024/390px 확인.


## 추천 출시안 — 구독 3단계 + 필요할 때 구매

사용자가 베이직/프리미엄 두 종류에 제한하지 않고 제안을 요청했다. 아래는 **제안**이며 실제 판매 상품/회원 권한을 변경하지 않는다.

| 상품 | 가격 | 최종 제공량 | 역할 |
|---|---:|---:|---|
| 스타터 | 월29,000원 | 20크레딧 | 부담 없이 시작 |
| 스탠다드 | 월69,000원 | 50크레딧 | 주력 상품, 꾸준히 제작 |
| 프로 | 월149,000원 | 110크레딧 | 많이 쓰는 고객, 가장 낮은 개당 가격 |
| 구매 크레딧 | 39,000원/회 | 기본20개, 와디즈 최초 구매23개 | 필요할 때 구매, 잔액 이월 |

구독 개당 가격은1,450원→1,380원→약1,355원으로 내려간다. 구매형은 와디즈 첫 구매에도 개당 약1,696원으로 구독보다 비싸다. 이월 편의와 구독의 가격 혜택을 맞바꾸는 구조다. 구독 수량은 이미 혜택을 포함한 최종 수량이며 추가15%를 중복 지급하지 않는다. 구매형의 +15%만 와디즈 첫 구매 혜택으로 제안한다. 반복 구매 제한은 상품 운영에서 별도 구현/확인해야 한다.

### 목표 마진 계산의 가정

크레딧1개를 제공하는 생성/실패/재생성 등의 예산을 **450원**, 서버·DB·지원·모집 이벤트·프로젝트 고정료 등 기타 합계 예산을 **구매금액의10%**로 가정한다. 와디즈 총15%, 매출 부가세는 포함가의1/11로 별도 차감한다. 450원은 실측 상한이 아니라 출시 예산을 잡는 가정이며 복잡한 카드 슬롯/고해상도/무료 분석 등의 모든 경로를 보장하지 않는다.

| 상품 | 구매금액 | 위 가정의 전체 비용 | 남는 금액 | 구매금액 대비 마진 |
|---|---:|---:|---:|---:|
| 스타터 | 29,000 | 약18,886 | 약10,114 | 약34.9% |
| 스탠다드 | 69,000 | 약46,023 | 약22,977 | 약33.3% |
| 프로 | 149,000 | 약100,295 | 약48,705 | 약32.7% |
| 구매형 최초23개 | 39,000 | 약23,645 | 약15,355 | 약39.4% |

따라서 이 조건 안에서는 구매금액30% 이상이 남는다. 실제 원가가450원을 넘거나 기타비용 합계가10%를 넘으면 다시 계산해야 한다. 가입자 몇 명에서나 이익을 보장하는 표가 아니다. 특히 초기 판매량이 적으면 프로젝트 고정료·서버 고정비가10%를 넘을 수 있다. 실제 인프라와 캠페인 예산을 입력한 도구 결과에서 재검증한다.

모집 이벤트는 회원가입 시2~3크레딧을 한 번 주는 제한된 체험을 출발안으로 둔다. 예를 들어300명×3개×450원=405,000원의 생성 예산이다. 인원 상한 없이 지급하거나 결제 보너스·후기 보너스를 무제한 중복하지 않는다. 광고와 무료 지급은 모두 위10% 예산 안에 넣는다. 3개월 구매 유효기간 동안의 운영비도 이 예산에서 적립한다.

### 도구 반영

와디즈 상품 전략의 **추천안 · 구독 3종 + 구매형 불러오기**로 위4개 상품을 비교할 수 있다. 추천안 버튼은 가격·제공량·가정 구매자 수만 불러오며 현재 작업 원가·인프라 입력을450원/10%로 덮어쓰지 않는다. 실제 입력과 위 예산 가정의 차이가 있으면 도구의 마진은 표와 달라진다. 새 마진 기준은 고객 구매금액이며 이전 공유안의 순매출 기준은 명시적으로 보존한다.
