# PDP STUDIO — 서비스 소개

텍스트 기반 상세페이지 생성에 그대로 붙여넣어 쓰기 위한 소개문이다.
아래 내용은 2026-07-27 기준 실제 구현을 확인하고 작성했다.

---

## 1. 붙여넣기용 — 짧은 버전

```
상품 사진 한 장이나 짧은 설명만 있으면 AI가 판매용 상세페이지를 통째로 만들어주는
웹 서비스입니다. 소상공인과 1인 셀러가 대상이고, 디자이너에게 맡기지 않아도
구성 설계부터 섹션 이미지 제작, 문구 편집까지 브라우저 안에서 끝납니다.
```

---

## 2. 붙여넣기용 — 자세한 버전 (권장)

정보가 많을수록 AI가 추정하는 부분이 줄어든다. 아래를 그대로 입력창에 넣으면 된다.

```
PDP STUDIO입니다. 온라인에서 물건이나 서비스를 파는 사람이 상세페이지를
직접 만들 수 있게 해주는 웹 서비스입니다.

주 고객은 소상공인, 1인 셀러, 소규모 브랜드의 마케팅 담당자입니다. 이들은 상세페이지가
매출을 좌우한다는 걸 알지만 디자이너에게 맡기면 비용과 시간이 크게 들고, 직접 만들자니
어떤 순서로 무슨 이야기를 해야 하는지부터 막힙니다.

시작하는 방법이 세 가지입니다. 상품 사진이 있으면 사진 한 장을 올리면 됩니다. 사진이
없으면 파는 것을 글로 적기만 해도 됩니다. 이미 쓰던 상세페이지가 있으면 그 이미지나
PDF를 올려서 구매전환 중심으로 다시 만들 수 있습니다.

어느 쪽으로 시작하든 AI가 먼저 상세페이지 구성을 설계합니다. 어떤 섹션을 어떤 순서로
놓을지, 각 섹션에서 무슨 말을 할지를 잡아서 보여줍니다. 이 단계에서 문구를 직접 고치고
섹션을 더하거나 뺄 수 있습니다. 확정하면 섹션별 이미지를 만들고, 편집기에서 글자 위치와
크기를 조정한 뒤 내보냅니다.

특징은 이렇습니다. 첫째, 예쁜 페이지가 아니라 구매로 이어지는 흐름을 설계합니다. 문제를
꺼내고 반론을 해소하고 행동을 유도하는 순서로 섹션을 배치합니다. 둘째, 한국어 카피가
이미지 안에 그대로 박힌 완성형 섹션을 만들 수 있어서 따로 디자인 툴을 열 필요가
없습니다. 셋째, 만들어진 이미지를 AI가 다시 검사해서 없는 브랜드 로고나 깨진 글자,
근거 없는 수치, 어색한 인체 묘사를 걸러냅니다. 넷째, 사람 모델 사진을 참조로 주면 여러
섹션에 같은 모델이 일관되게 나옵니다.

회원이 따로 AI 서비스에 가입하거나 API 키를 준비할 필요는 없습니다. 가입 신청하고
이메일 인증과 관리자 승인을 거치면 바로 씁니다. 구성 분석은 무료이고 성공한 이미지
장수만 월 한도에서 차감됩니다. 작업 중인 초안은 30초마다 브라우저에 자동 저장돼서
창을 닫아도 이어서 할 수 있습니다.

모바일에서 보는 세로형(9:16)이 기본이고 정사각형, 가로형 등 다섯 가지 비율을 고를 수
있습니다.
```

## 3. 확인된 사실 목록 (참고용)

소개문을 고치실 때 근거로 쓰시면 된다.

**진입 방식 3가지**

| 방식 | 입력 | 경로 |
|------|------|------|
| 새로 만들기 (이미지) | 상품 사진 1장 | `/create` |
| 새로 만들기 (텍스트) | 자유 형식 글 | `/create` |
| 리디자인 | 기존 상세페이지 이미지·PDF | `/redesign` |

**공통 흐름**

```
구성 설계 → (텍스트 진입은 시나리오 확인·수정 단계 추가) → 섹션 이미지 생성 → 편집 · 내보내기
```

**출력**

- 통이미지(full-image): 한국어 카피가 이미지에 직접 렌더된 완성형 섹션 — 현재 기본값
- 텍스트편집(editable): 글자 없는 이미지 + 편집기에서 문구 오버레이
- 섹션 수: 이미지 진입 4~6개, 텍스트 진입 4~7개
- 비율: 1:1 · 3:4 · 9:16 · 4:3 · 16:9 (9:16 기본)

**품질 장치**

- 생성 이미지 QA 게이트: 카피에 없는 브랜드/로고, 깨진 글자, 근거 없는 수치, 인체 왜곡 검사
- 모델 이미지 참조: 지정한 인물이 여러 섹션에 일관되게 등장
- 리디자인은 지식파일(RAG) 기반으로 근거를 붙여 생성

**회원 · 과금**

- 가입 신청 → 이메일 인증 → 관리자 승인 → 이용
- 회원은 AI 키를 준비하지 않는다 (운영자 서버 키 사용)
- 구성 분석은 무료, 성공한 이미지 장수만 월 한도에서 차감
- 작업 초안은 브라우저에 30초 자동 저장

## 4. 비워둔 항목

아래는 코드에서 확인할 수 없어 소개문에 넣지 않았다. 실제 값이 정해지면 채워야 한다.

- **가격** — 월 요금제와 금액
- **월 이미지 한도** — 요금제별 장수 (`monthly_quota`는 회원마다 설정되는 값이라 고정값이 없다)
- **정식 출시 여부** — 현재는 관리자 승인제로 운영 중
- **실적·후기** — 사용자 수, 전환율 개선 사례 등 근거 있는 수치

가격이 비어 있으면 AI가 추정해서 채우고, 그 사실을 시나리오 화면의
"AI가 채운 부분"에 표시한다.
