- **커밋·푸시·병합·배포·운영 SQL 실행 금지.** 사용자가 요청할 때만 한다

- 사용자에게 보이는 오류 문구는 내부 구조를 흘리지 않는다. 화질 타협 금지(원본 바이트 보존). 운영 서버 램 911MB
- 마이그레이션 `202610030001_pdp_documents.sql` 은 **아직 운영에 실행되지 않았다**는 전제로 이 파일을 고친다. 고친 뒤에도 운영에서는 한 번만 실행한다
- 범위 밖(리뷰 결과 §7, 기존 표 경로 보안, 리디자인)은 고치지 않는다. 고치다 새로 발견한 범위 밖 문제는 기록만 한다
