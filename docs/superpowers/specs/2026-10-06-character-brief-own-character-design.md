# 캐릭터 만들기 — 의도 정리(LLM) · 내 캐릭터 칸 설계

2026-10-06 · 사용자 요청 원문은 대화에 있다. 이 문서는 그 대화에서 정한 것만 적는다.

## 1. 왜

### 문제 — 「3등신 고양이」에 머리 셋

- 입력: 「고양이인데 3등신에 귀여운 캐릭터를 만들어줘」, 종류 **캐릭터**, 그림체 **3D**, 모델 표준형·속도형
- 결과: 머리가 셋인 고양이
- 원인(코드 확인): 캐릭터 만들기는 **사용자가 친 한국어를 그대로** 이미지 모델에 보낸다. 중간에 해석하는 단계가 없다.
  「캐릭터」 종류는 「고유 비율을 지켜라」라고 말하므로 우리 지시문과는 안 부딪혔다 — 이미지 모델이 「3등신」을 「머리 3개」로 읽었다.
- 같은 구멍이 더 있다. 용어(등신·SD·치비)를 안 풀어 주고, 여러 요청을 정리하지 않고, 단추 값과 글이 부딪혀도 모델에게 맡긴다.
  이 한국어는 옆·뒤 각도를 그릴 때도 그대로 다시 쓰인다.

### 추가 기능 — 내 캐릭터를 레퍼런스 느낌으로

지금은 그림을 한 장만 붙인다. 「내가 가진 캐릭터」를 「레퍼런스 캐릭터」처럼 바꾸려면 두 장이 필요하다.

## 2. 정한 것

### 1단계 — 의도 정리 담당(LLM)

| 항목 | 정한 것 |
|---|---|
| 하는 일 | 사용자 글 + 고른 종류·그림체·첨부 상황을 받아 **이미지 모델이 오해하지 않는 영어 묘사**로 정리 |
| 하지 않는 일 | 사용자가 말하지 않은 생김새(색·옷·소품·종)를 **지어내지 않는다** |
| 용어 | 「N등신」 = 머리 하나, 전체 키가 머리 N개 길이. 숫자가 몸 부위 개수로 읽힐 수 있으면 개수를 적는다(머리 하나·눈 둘) |
| 나눔 | **정체성**(누구인가·생김새·비율·옷) / **이번 한 장 요청**(자세·표정·드는 것) |
| 저장 | 정체성을 「AI 가 정리한 정체성」 칸(`identity_prompt`)에 저장하고 옆·뒤 각도와 다시 만들기에 쓴다. 사용자가 친 말은 「이렇게 말했습니다」(`source_prompt`)에 그대로 남는다 |
| 모델 | `claude-sonnet-5`(1M 토큰 입력 $2·출력 $10) — 이 저장소의 기본 글 모델. 사용자 결정 2026-10-06(하이쿠 대신 상위 모델). 환경값 `CHARACTER_BRIEF_MODEL` 로 바꾼다 |
| 끄기 | 환경값 `CHARACTER_BRIEF=off` 면 지금처럼 원문 그대로 간다 — 배포 없이 되돌린다 |
| 실패 | LLM 이 실패·느림·이상한 답이면 **원문 그대로 만든다.** 그림 만들기는 멈추지 않는다 |
| 크레딧 | LLM 값은 회원 크레딧에서 깎지 않는다. 운영 원가로만 기록한다(기존 계량기 `withLlmMeter`) |

### 2단계 — 내 캐릭터 칸

| 항목 | 정한 것 |
|---|---|
| 자리 | 「무엇을 만들까요」 칸 아래 **「내 캐릭터 · 선택」** |
| 넣는 길 | 「새 이미지 올리기」·「라이브러리」 — 참고할 그림과 같다 |
| 장수 | 내 캐릭터 1장 + 참고할 그림 1장 |
| 내 캐릭터만 | 지금의 「참고할 그림 + 이 캐릭터 뽑아내기」와 **같게** 동작한다. 그림체는 지금처럼 고른다 |
| 둘 다 | 내 캐릭터의 **생김새·색·옷·소품은 유지**, **화풍과 몸 비율(등신·체형)은 레퍼런스**를 따른다 |
| 뽑아내기 단추 | 내 캐릭터가 있으면 「이 캐릭터 뽑아내기」는 **흐리게 막고** 이유를 적는다. 역할은 「레퍼런스 스타일」로 고정 |
| 그림체 단추 | 둘 다 있으면 「레퍼런스 스타일」로 고정, 나머지는 흐리게 막고 이유를 적는다(「참고할 그림을 빼면 고를 수 있습니다」) |
| 기존 뽑아내기 | 그대로 둔다(내 캐릭터 없이 참고할 그림만 넣을 때) |
| 레퍼런스만 | 내 캐릭터 없이 「레퍼런스 스타일」만 써도 **화풍 + 몸 비율**을 가져온다. 사용자가 글로 비율을 적으면 글이 이긴다 |
| 그림 이름표 | 이미지 모델에 「Image 1 = 내 캐릭터(유지), Image 2 = 레퍼런스(화풍·비율)」라고 적어 보낸다 |

### 순위 (부딪힐 때)

사용자가 친 말 > 내 캐릭터의 생김새 > 레퍼런스. **몸 비율만은 예외로 레퍼런스가 내 캐릭터를 이긴다.**

## 3. 하지 않는 것

- 카드뉴스처럼 여러 장 + 역할 고르기는 만들지 않는다(사용자 결정: 두 장이면 된다)
- 저장해 둔 「내 캐릭터」 목록에서 고르는 길은 만들지 않는다(요청에 없음)
- DB 구조는 바꾸지 않는다 — `source_prompt` · `identity_prompt` 두 칸이 이미 따로 있다
- `CharacterStudio.tsx`(이미 1281줄) 를 나누는 정리는 하지 않는다. 새 칸은 새 파일로 뺀다

## 4. 확인 방법

- 단위 시험: 지시문·LLM 요청·응답 해석·라우트 연결·화면 규칙
- 실제 LLM 로 표본 6개 돌려 정리 결과를 눈으로 본다(「3등신」 → 머리 하나)
- 배포 뒤 사용자가 실제로 만든다: 같은 「3등신 고양이」, 내 캐릭터 + 레퍼런스
