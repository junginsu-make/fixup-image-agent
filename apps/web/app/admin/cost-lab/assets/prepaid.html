작업 가격과 차감 크레딧

원가와 목표 마진으로 정한 공통 단가입니다. 충전액·고객 수·사용률을 바꿔도 이 단가는 변하지 않습니다.

작업모델작업당 이미지작업 비중예상 AI 원가작업 1회 판매가 = 차감 크레딧이미지 1장당 평균충전금으로 가능한 횟수

장당 금액은 기획비를 포함한 작업 가격을 이미지 수로 나눈 평균입니다. 각 행의 최대 횟수는 그 기능에만 전액 사용하는 경우이며 서로 합산할 수 없습니다. 작업 판매가는 소수점 둘째 자리까지 올림해 정하고 같은 수의 크레딧을 차감합니다. 0.4원은 0.4크레딧이며, 매번 1원으로 올리지 않습니다.

계산 기준과 원가 출처

이미지·글 원가는 기존 MCS 비용 전략실에서 확인한 저장소 가격표를 사용합니다. 공급사 실시간 청구서와 대조한 실측 원가는 아닙니다. 단가표 기준: 분석한 저장소.

작업 판매가 = 예상 AI 원가 ÷ [(1 − 작업 목표 마진율) ÷ (1 + 부가세율) − 결제 수수료율]. 단가는 충전금 전액 사용 기준으로 정합니다. 결제 수수료율은 충전액에 적용하고, 사용분 매출에서 해당 월 수수료 전액을 차감해 예상 이익을 계산합니다.

월 사용 금액 = 충전 고객 수 × 인당 월 충전 횟수 × 충전액 × 사용률. 사용분 매출 = 월 사용 금액 ÷ (1 + 부가세율). 월 이익 = 사용분 매출 − 생성비 − 충전 결제 수수료 − 고객 지원비 − 무료 제공 원가 − 고정비. 작업 비중은 작업 건수의 상대 비중이며 합계를 자동으로 정규화합니다.

생성 배수는 성공 이미지에 추가로 드는 서비스 부담 생성 비용입니다. 최종 실패 비용은 별도로 반영합니다. 고객이 유료로 다시 생성한 작업은 새 작업으로 차감합니다. 무료 제공 원가는 이번 달 공급사에 지불할 별도 비용을 직접 입력합니다.

같은 달 충전분의 사용을 가정하는 경영 시뮬레이션입니다. 이전 달 잔액의 사용·환불·잔액 만료·실제 회계 처리와 세무 신고를 구현한 결제 장부는 아닙니다. 실제 서비스나 고객 잔액은 변경하지 않습니다.
